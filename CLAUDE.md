# Contexto para Claude Code

Leia primeiro o `AGENTS.md` na raiz. Ele contém as regras compartilhadas do projeto.

Projeto: **Bairro na Mesa** (GS 2026.2 – CitizenTech). App Flutter do morador, sem login, consumindo a API Spring Boot do projeto. Domínio completo em `../Bairro na Mesa – Resumo do Projeto (GS 2026.2).md`.

Antes de implementar:
- Consulte `README.md`.
- Consulte `.ai/context/project-context.md` e `.ai/context/evaluation-rubric.md`.
- Consulte os documentos de arquitetura relacionados à tarefa.

Siga obrigatoriamente:
- Flutter/Dart.
- `http` para API REST.
- `SharedPreferences` para preferência de onboarding.
- `setState` como gerenciamento de estado exigido pela avaliação.
- Separação entre telas, widgets, models e services.
- Testes e validação sem inventar resultados.

Não duplique instruções extensas aqui. Se houver divergência, sinalize e siga o `AGENTS.md` e o enunciado.
